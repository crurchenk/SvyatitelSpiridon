# Cайта Свято-Спиридоновского храма

Статический сайт для GitHub Pages.

## Что уже есть
- Главная страница с фотографией.
- Разделы «О храме», «Расписание», «Контакты».
- Страница «Подать записку».
- Выбор «О здравии / Об упокоении».
- Добавление имён и автоматический подсчёт суммы.
- Заглушка для будущей ссылки/интеграции ПСБ.

## Что нужно будет заменить
1. Актуальные реквизиты и контакты.
2. Реальное расписание.
3. Цену одного имени.
4. PAYMENT_URL в `js/notes.js` — после подключения платёжного сервиса ПСБ.
5. Отправку заявки на почту (например, отдельным сервисом формы или серверным webhook).
